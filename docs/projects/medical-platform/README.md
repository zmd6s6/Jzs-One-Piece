# 医疗信息化平台研发与交付

> 这是本仓库唯一的项目入口。所有实践内容（事故、选型、复盘）都在这里，基础知识在各自的域（左侧导航）。

## 项目背景

医疗信息化产品线，长期以"裸机 + 解压即运行包"方式交付。推动容器化与集群化后，经历了从零搭建 K8s 集群、镜像流水线、部署模板、排障手册的完整过程——踩过的坑全部记录在这里。

**约束条件**（决定了所有选型）：

| 约束 | 影响 |
|---|---|
| 机器少（客户现场 2 台、内部 2 台） | 双节点是折中不是推荐做法 |
| 断网 | 镜像离线分发，无公网拉取 |
| 无专职运维 | 方案要能"照手册执行" |
| 中间件由现场既有系统提供 | 需要把集群外地址以集群内名字引用 |
