## Planned Topics

后续可从学习产物中提炼为稳定知识页：

- 金融市场与资产类别
- 利率、通胀、信用与流动性
- 财务报表与企业质量
- 估值方法
- 行业供需与周期
- 投资组合与风险管理
- 投资备忘录与复盘

即时行情、未经验证的观点和临时研究应与长期知识分开，避免把短期判断写成永久事实。
