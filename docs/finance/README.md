## 使用原则

1. 先读手册建立机制。
2. 再用案例看机制在真实数据里如何出现。
3. 用48天计划完成计算、查年报、画产业链等训练。
4. 最终把研究写入 Investment Memo。
5. 实时行情、未经验证的观点和临时研究不要写成永久事实。
