# 48天金融基础实战学习计划

## 目标

这不是金融考试大纲，也不是短线交易课程。目标是在48个训练日后，能够独立完成一份基础投资分析：知道自己研究的资产是什么、公司如何赚钱、行业处于什么周期、估值在表达什么预期，以及什么条件下应该继续观察或重新评估。

## 执行规则

- 每天 45～60 分钟，每周 6 天；第7天用于休息或补欠账。
- 每天必须留下一个可检查产物：表格、计算、逻辑图、事实卡或备忘录。
- 不以“看了多少视频/文章”作为完成标准。
- 前6周不急于给买卖结论；先训练事实、机制和数据。
- 案例尽量固定，避免每天换标的。可使用一只消费股、一只制造/成长股、一只周期股、一只宽基ETF和一只行业ETF作为学习样本；这些只是训练样本，不构成投资推荐。
- 所有实时数据写明日期和来源。

## 如何判断自己真的学会了

不要用“我知道PE/ROE/利率是什么”判断。完成计划后，应该能对一个陌生标的依次回答：

1. 我买的到底是什么资产？
2. 企业或底层资产靠什么产生现金流？
3. 当前行业供需和周期位置是什么？
4. 盈利质量和资产负债表如何？
5. 当前价格隐含了什么增长与风险预期？
6. 哪些事实能证明我的判断错误？
7. 如果要执行，进入、退出和仓位规则是什么？

如果这些问题还需要依赖他人的一句结论，说明对应模块需要回炉。
