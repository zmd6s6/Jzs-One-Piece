# 如何读三张财务报表

## 1. 财报不是为了背会计科目

投资者阅读财报要回答五个问题：公司靠什么赚钱？收入和利润质量如何？利润有没有变成现金？扩张需要投入多少资本？资产负债表能否扛住逆风？

三张表必须一起读。

# 一、利润表：这一段时间赚了多少钱

最核心结构可以理解为：`营业收入 - 营业成本 = 毛利润；再减费用、利息和税，最终得到净利润`。

## 2. 收入

先看过去3～5年收入、同比增速、分产品、分地区、分渠道、销量和价格。

`收入 = 销量 × 单价`。

收入增长可能来自销量、涨价、并购并表或渠道压货。同样+20%，质量完全不同。

## 3. 毛利率

`毛利率 = (收入 - 营业成本) / 收入`。

毛利率变化通常由售价、原材料成本、产品结构、产能利用率、会计口径或汇率驱动。不要看到毛利率下降就直接说竞争恶化。

## 4. 费用率

常见有销售费用率、管理费用率和研发费用率。必须结合商业模式理解：软件、零售和重资产制造的费用结构天然不同。

## 5. 净利润与扣非净利润

净利润可能包含资产处置、补助、投资收益和公允价值变化。分析主营经营趋势时应同时观察扣非利润，但仍要看具体项目，不能机械相信“扣非=真实利润”。

# 二、资产负债表：某个时点拥有什么、欠什么

基本恒等式：`资产 = 负债 + 股东权益`。

## 6. 现金

现金多通常提高安全性，但还要问是否受限、是否同时背负高息债务、是否长期闲置降低资本效率，以及是否属于特殊业务中的客户资金。

## 7. 应收账款

应收上升可能来自销售增长，也可能是客户账期拉长、公司放宽信用或客户质量恶化。一个实用比较是：`应收增速 vs 营收增速`。

若应收持续明显快于收入，继续查账龄、坏账计提和客户集中度。

## 8. 存货

存货上升可能是旺季备货、提前采购、扩产，也可能是产品卖不出去。继续看存货周转、跌价准备、产成品比例和行业价格。

## 9. 固定资产与在建工程

重资产行业需要关注在建工程、转固、产能利用率和折旧。扩产后如果需求不及预期，可能同时出现价格下降和固定成本上升。

## 10. 债务

不要只看负债率。至少拆短期借款、长期借款、债券、租赁负债、利率和到期时间。真正危险的组合往往是：`高债务 + 短久期 + 现金流弱 + 融资环境收紧`。

# 三、现金流量表：钱到底有没有进来

## 11. 经营活动现金流（CFO）

长期看，高质量企业需要让会计利润转化成现金。可以观察 `CFO / 净利润`，如果连续多年明显偏低，继续追查应收、存货、预付款和收入确认。

## 12. 投资活动现金流

包括买固定资产、建厂、收购和金融资产投资。流出大不一定坏，关键是资本投入的未来回报。

## 13. 融资活动现金流

包括借款、还债、增发、回购和分红，它告诉你公司如何与资本提供者互动。

# 四、自由现金流

一个初学者可用的粗略直觉是：`FCF ≈ 经营现金流 - 资本开支`。

不同估值体系会进一步区分FCFF、FCFE并做营运资本等调整。最重要的是理解：会计利润不是股东可以立即拿走的现金。

两个企业都赚100亿，一个维持业务只需投入10亿，另一个需要投入90亿，它们的经济属性完全不同。

# 五、三张表如何联动

销售一批货时，利润表可以先确认收入和利润；如果客户没付款，资产负债表的应收增加，经营现金流不会同步增加。因此只看利润表会遗漏收款质量。

公司借100亿建厂时，资产负债表债务和在建工程上升，融资现金流先流入，投资现金流再流出，投产后收入、成本和折旧才逐步进入利润表。

# 六、财报阅读实战顺序

1. 先理解业务：产品、客户、收入结构、行业位置。
2. 拉5年核心数据：营收、净利润、毛利率、ROE、CFO、资本开支、债务。
3. 找异常：利润和现金流背离、毛利率突变、应收/存货快于收入、大额扩产、债务期限变化。
4. 回到年报查原因：管理层讨论、分部、风险、关联交易、资本开支、审计意见。

# 七、财务比率不是评分游戏

高存货对白酒与消费电子意义不同，高负债对银行与制造业意义不同，高研发对软件与矿山意义不同。正确问题不是“这个比率高不高”，而是“为什么是这个水平、趋势如何、同行如何、商业模式是否支持”。

# 八、值得继续调查的警示信号

- 利润增长而CFO长期跟不上；
- 应收和存货远快于收入；
- 频繁更换审计机构或出现非标意见；
- 大额关联交易；
- 大额商誉且被收购业务恶化；
- 长期依靠融资维持经营现金缺口；
- 利润主要来自非主营处置或公允价值变化。

单个信号不能证明造假或恶化，但值得进一步核验。

## 小结

财务分析的核心是验证：`商业活动 → 会计利润 → 资产负债变化 → 真实现金流 → 股东最终可获得的价值`。
