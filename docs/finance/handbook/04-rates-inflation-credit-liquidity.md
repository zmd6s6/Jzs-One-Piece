# 利率、通胀、信用与流动性

## 1. 宏观研究不是猜GDP

个人投资者最有用的宏观框架是回答：资金价格在升还是降？信用在扩张还是收缩？通胀压力如何？实体需求强弱如何？政策在收紧还是放松？市场已经预期了多少？

核心变量可以浓缩为：`增长 + 通胀 + 利率 + 信用 + 流动性`。

## 2. 名义利率与实际利率

粗略地：`实际利率 ≈ 名义利率 - 预期通胀`。

名义利率3%、通胀预期2%，实际回报约1%；若通胀5%，实际利率约-2%。实际利率会改变持有现金、债券、黄金、成长股和房地产的机会成本。

## 3. 央行真正控制什么

央行通常最直接影响短期政策利率和银行体系流动性，并不能机械决定每一个期限、每一笔贷款的最终价格。

以美联储为例，FOMC设定联邦基金利率目标区间，并通过准备金利率、隔夜逆回购等工具影响短端利率。随后传导到债券收益率、贷款利率、汇率、风险溢价、企业融资和家庭消费。

简化链条：`政策利率/预期 → 市场利率与金融条件 → 消费/投资 → 就业/产出/通胀`。

传导存在时滞，也不是固定比例。

## 4. 为什么长期利率不完全听央行

10年期国债收益率可以粗略拆为：`未来短期利率预期 + 通胀预期 + 期限溢价 + 供需因素`。

因此央行降息时，如果市场同时担心长期通胀、财政赤字或债券供给，长端收益率仍可能上升。

## 5. 加息如何影响股票

### 路径A：企业盈利

`利率上升 → 借款变贵 → 居民/企业需求放缓 → 资本开支下降 → 盈利压力`。

### 路径B：估值

股票价值来自未来现金流折现。折现率上升，同样的未来现金流今天价值更低。越依赖遥远未来利润的资产，对折现率越敏感。

## 6. 为什么降息不是“股票必涨”

软着陆式降息可能同时改善估值和融资条件；危机式降息往往伴随失业、信用收缩和盈利恶化，盈利下修可能压过折现率下降。

所以看到降息，第一问是“为什么降”，第二问是“市场之前已经预期多少”。

## 7. 通胀

通胀是总体价格水平持续上升，不是所有商品同时涨。常见指标有CPI、PPI、PCE和核心通胀。

投资者真正要问：通胀来自需求还是供给？是否持续？工资是否形成反馈？央行是否需要改变利率路径？

## 8. 信用比单看货币数量更接近实体融资

在中国宏观研究中可结合M1/M2、人民币贷款、社会融资规模、企业中长期贷款、政府债融资和信用利差。

社会融资规模回答的是：实体经济从金融体系获得了多少融资、通过什么渠道获得。M2高并不自动等于经济强，如果企业和居民借贷意愿弱，资金可能停留在存款和金融体系。

## 9. 流动性的三个层次

- **银行体系流动性**：金融机构获得短期资金是否容易；
- **市场流动性**：证券能否低成本快速成交；
- **宏观信用流动性**：企业居民是否愿意借、银行是否愿意贷。

三者可能不同步。

## 10. 汇率如何进入资产定价

汇率受相对利率、通胀、贸易资本流、风险偏好和政策预期共同影响。它会影响跨境ETF、进口成本、出口收入、外币债务和人民币计价海外资产收益。

## 11. 一张宏观状态表

| 模块 | 观察数据 | 方向 |
| --- | --- | --- |
| 增长 | PMI、工业、消费、就业 | 改善/恶化 |
| 通胀 | CPI/PPI/PCE | 上行/下行 |
| 利率 | 政策利率、10Y国债 | 上行/下行 |
| 信用 | 社融、贷款、信用利差 | 扩张/收缩 |
| 流动性 | 资金利率、央行操作 | 宽松/紧张 |
| 汇率 | 主要货币对 | 升值/贬值 |

重点看变化方向，不必创造一个神秘的宏观总分。

## 12. 如何阅读央行材料

### 中国

优先阅读人民银行货币政策执行报告、金融统计数据报告、社会融资规模统计和公开市场操作。顺序可先看政策思路和专栏，再看信贷利率与宏观数据。

### 美国

优先阅读FOMC statement、经济预测摘要、主席发布会、Monetary Policy Report和FRED数据，不要只看媒体的“鹰派/鸽派”标签。

## 13. 宏观推导模板

`政策为什么发生 → 直接影响哪个利率/信用变量 → 哪类现金流最敏感 → 哪类估值最敏感 → 市场是否已经提前定价 → 我的持仓暴露在哪个因子`。

## 小结

宏观分析的目标不是精确猜下一次降息，而是理解**资金价格和信用环境变化时，哪些现金流和估值会被重新定价**。
