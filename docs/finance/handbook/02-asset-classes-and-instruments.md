# 股票、债券、基金与 ETF

## 1. 不要按产品名字判断风险

判断任何金融产品，第一步不是看名字，而是问：**底层持有什么资产？现金流从哪里来？我排在什么偿付顺序？**

“基金”只是法律和运营结构，“ETF”是交易和申赎结构。真正决定长期收益和风险的仍是底层资产。

## 2. 股票：剩余索取权

股票代表企业所有权的一部分。股东拥有的是企业在支付工资、原材料、税、利息、债务和其他合同义务后的剩余经济权益。

股票长期回报可以粗略拆为：

`股东回报 ≈ 盈利增长 + 分红/回购 + 估值倍数变化`

例如每股收益增长20%，但PE从30倍降到20倍，估值压缩可能抵消甚至超过盈利增长。这就是为什么公司业绩增长不等于股价一定上涨。

股票的主要风险包括商业模式被替代、盈利下降、竞争加剧、高杠杆、治理问题、估值过高、股权稀释和风险偏好变化。

## 3. 债券：合同索取权

债券本质上是借款合同，通常规定面值、票息、到期时间、偿付顺序和契约条款。债权人通常优先于普通股股东获得偿付。

债券收益来源包括票息、到期本金和二级市场价格变化。

### 为什么市场利率上升，旧债价格下降

若旧债面值1000元、票息3%，新发行同风险债券收益率已经5%，投资者不会愿意仍以1000元购买旧债。旧债需要降价，使新买家的实际收益率提高。

债券还承担利率风险、信用风险、久期风险、流动性风险和再投资风险，因此“债券=保本”是错误的。

## 4. 基金：资产容器

主动基金由基金经理决定买什么、买多少和何时调整，投资者还承担管理人能力、风格漂移、费用与换手成本。

指数基金以跟踪指数为目标。研究重点转向指数选样规则、加权方式、成分股集中度、行业暴露、再平衡、跟踪误差和费用。

## 5. ETF：交易所交易的基金

ETF通常同时具有基金份额、盘中交易、一级申赎和二级市场买卖。做市和申赎套利机制通常会推动市场价格靠近净值，但在跨境、停牌或极端行情下仍可能出现明显折溢价。

分析 ETF 的顺序：

1. 跟踪什么指数？
2. 指数如何选样？
3. 如何加权？
4. 单只成分股上限多少？
5. 行业集中度多高？
6. 是否有汇率、跨境时差、额度风险？
7. 费用率和跟踪误差如何？
8. 流动性和买卖价差如何？

### 宽基 ETF

覆盖多个行业，主要降低个股特有风险，但仍承担整体股票市场风险。市值加权指数在某些时期也可能集中于少数大市值行业。

### 行业/主题 ETF

本质是对某类风险因子的集中暴露。买了几十只同主题股票，不等于实现充分分散。

## 6. 商品、黄金与期货

商品现货是铜、铝、原油、黄金等真实商品，价格主要受供需、库存、运输、产能、宏观需求、美元和利率驱动。

期货首先是一份标准化未来交割合约，可用于企业套保、价格发现、套利或投机。期货最大的附加风险来自保证金制度和杠杆：小幅价格变化可以造成大幅账户波动甚至强平。

## 7. 期权：非线性权利

期权赋予买方在特定时间以约定价格买入或卖出标的的权利。核心变量包括标的价格、行权价、到期时间、波动率、利率和分红。

期权不是简单的“高杠杆股票”，还存在时间价值衰减和波动率风险。初学阶段应先学股票和债券。

## 8. 现金也是资产

现金名义波动小、流动性高、提供未来选择权，但长期受到通胀侵蚀。因此不满仓也是一种主动资产配置。

## 9. 资产选择的统一六问

| 问题 | 目的 |
| --- | --- |
| 底层资产是什么？ | 防止被产品名字误导 |
| 现金流从哪里来？ | 找收益来源 |
| 谁先拿钱、谁后拿钱？ | 识别资本结构风险 |
| 收益由哪些变量驱动？ | 找核心因子 |
| 最坏情况下如何亏钱？ | 定义风险 |
| 流动性和杠杆如何？ | 判断是否可能被迫退出 |

## 小结

投资工具只是包装。统一的理解链条是：`底层资产 → 现金流 → 风险承担顺序 → 定价变量 → 流动性/杠杆`。
