# 估值：价格、价值与预期

## 1. 估值在解决什么问题

基本面分析回答“公司怎么样”，估值回答“以现在这个价格买，未来回报是否值得承担风险”。

好公司和好投资是两个不同问题。企业质量很高，但如果价格已经提前透支十年的乐观预期，投资回报仍可能很差。

## 2. 价格与价值

市场价格是当前边际交易结果；内在价值是对未来可分配现金流的估计。价值不是一个精确数字，而更像一个区间。

估值的本质不是寻找神奇倍数，而是把四件事放到一起：`现金流 + 增长 + 风险 + 时间`。

## 3. PE

`PE = 股权市值 / 归母净利润 = 股价 / 每股收益`。

PE可以理解为市场为1元当前利润支付多少价格，但它绝不是“回本年限”。利润会增长、下降，资本结构也会变化。

### PE为什么高

可能因为：增长快、增长持续时间长、资本回报高、现金流稳定、风险低，或者纯粹因为市场过度乐观。

### PE为什么低

可能因为：增长低、周期高点、治理差、负债高、行业衰退、市场恐慌，也可能确实被低估。

所以低PE是研究起点，不是结论。

## 4. 周期股的PE陷阱

周期企业利润在商品价格高点可能异常高，此时 `市值/峰值利润` 会显得非常低。随后商品价格下降、利润回归中枢，PE可能在股价下跌时反而上升。

周期股需要结合正常化利润、资产价值、成本曲线、商品价格和供需周期分析。

## 5. PB

`PB = 股权市值 / 净资产`。

PB常用于银行、保险、资源和资产型企业，因为其账面资产与经营能力关系更紧。但仍需问：账面资产质量如何？ROE是多少？是否存在减值？

低PB但长期低ROE的公司未必便宜。如果1元净资产只能持续产生很低回报，市场给予折价有合理性。

## 6. PS

`PS = 市值 / 营业收入`。

适合尚未稳定盈利但收入有意义的公司，但收入本身不属于股东。必须继续研究未来毛利率、费用率、资本需求和最终利润。

高收入、永远不赚钱的商业模式没有因为PS低就自动有价值。

## 7. EV 与 EV/EBITDA

`EV ≈ 市值 + 有息债务 - 现金`。

EV/EBITDA常用来比较资本结构不同的企业，但EBITDA忽略资本开支。对于必须持续大量更新设备的企业，EBITDA可能显得过于乐观。

## 8. 股息率

`股息率 = 每股现金分红 / 股价`。

高股息可能来自稳定现金流，也可能来自股价暴跌。需要检查分红是否可持续、企业是否为了分红举债、未来是否需要大量资本开支。

## 9. DCF 的直觉

DCF（现金流折现）的核心逻辑是：未来收到的钱不等于今天的钱。

简化表达：`价值 = Σ 未来现金流 / (1 + 折现率)^t`。

DCF最重要的不是Excel模型，而是迫使你明确：

- 未来收入和利润率；
- 再投资需求；
- 自由现金流；
- 风险/折现率；
- 高增长能持续多久；
- 终值假设。

模型对长期假设非常敏感，因此应做情景分析，而不是给出一个小数点后两位的“目标价”。

## 10. 反向DCF / 隐含预期

一个更实用的方法是反过来问：**当前价格要求公司未来做到什么？**

例如当前价格只有在未来十年保持20%利润增长才合理，那么真正的研究重点不是“PE高不高”，而是这20%能否持续十年。

这能把估值问题转为业务问题。

## 11. 增长的价值取决于资本回报

增长并非免费。如果企业为了增加1元利润需要投入大量低回报资本，增长价值有限。高价值增长通常来自高ROIC上的再投资。

## 12. 安全边际

安全边际不是简单“比目标价低20%”。它本质上是为以下错误留空间：

- 预测错误；
- 行业周期判断错误；
- 管理层执行不达预期；
- 宏观环境变化；
- 估值模型口径错误。

不确定性越高，需要的安全边际通常越大。

## 13. 相对估值的正确用法

比较同行时先确认：

1. 商业模式是否相似；
2. 增长率是否相似；
3. 资本结构是否相似；
4. 会计口径是否相似；
5. 周期位置是否相似。

否则“同行平均PE”可能没有意义。

## 14. 历史估值分位的局限

历史分位回答“和自己过去比贵不贵”，却不回答公司是否已经发生结构变化。

如果增长中枢、利率环境、竞争格局或商业模式改变，过去10年的估值中枢未必适用。

## 15. 估值分析固定模板

| 问题 | 需要回答 |
| --- | --- |
| 当前价格 | 市值/EV是多少？ |
| 当前盈利 | 利润、FCF是否正常化？ |
| 增长 | 来自哪里，能持续多久？ |
| 资本回报 | 增长需要多少新增资本？ |
| 风险 | 什么会永久损害现金流？ |
| 相对估值 | 同行差异为何存在？ |
| 历史估值 | 当前与过去差异原因？ |
| 隐含预期 | 市场要求未来做到什么？ |
| 安全边际 | 哪些错误已被价格缓冲？ |

## 16. 常见估值错误

- PE低就叫低估；
- 公司增长快，所以任何价格都能买；
- 用峰值利润做估值；
- DCF假设过度精确；
- 用同一个PE标准比较所有行业；
- 只看历史估值，不看基本面结构变化。

## 小结

估值不是寻找一个神奇指标，而是判断：**当前价格隐含的未来，是否比你基于证据能合理相信的未来更乐观或更悲观。**
