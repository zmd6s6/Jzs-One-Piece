### 按路径学

1. [市场利率与债券定价](./bond-market-rates-and-pricing.md)：认识票息、面值、到期收益率，亲手计算利率变化下的债券价格。
2. [久期与利率风险](./bond-duration-interest-rate-risk.md)：理解“利率变动0.5个百分点”如何影响持有市值。
3. [债券与债券基金的区别](./bond-vs-bond-fund.md)：理解为何普通债基没有统一到期还本日。
4. [债券基金长期收益与净值](./bond-fund-long-term-returns.md)：区分利息、资本利得、复利、分红与未来预期收益。

**专题验收**：能不看笔记解释“利率上涨旧债为什么跌”；能对3000元、假设修正久期6年的债券组合进行±0.5个百分点的压力测试；能说清单只债券与开放式债基在“到期”上的区别；能解释为什么历史长期上涨不代表未来收益保证。

### 按决策查

- **期限短、对回撤敏感**：先检视资金何时需要使用，再讨论基金久期与流动性。
- **比较短债和长债**：优先比较当前收益率、修正久期、信用风险与费用，而不是只看过去一年涨幅。
- **比较同一基金A/C份额**：看实际申购费优惠、销售服务费、赎回费和预计持有期限。
- **评估长期投资逻辑**：区分净利息收入与利率下行带来的历史价格收益，不外推历史净值斜率。

## 手册的核心原则

### 1. 先理解资产，再讨论价格

任何投资先问：底层资产是什么，谁在产生现金流，现金流如何分配，谁承担风险。

### 2. 事实、解释、预测分层

- **事实**：已经披露的数据、合同、规则、财报。
- **解释**：你对事实之间因果关系的理解。
- **预测**：未来可能发生什么。

三者必须分开写。很多投资错误来自把“预测”写成“事实”。

### 3. 价格不是价值，价值也不是确定值

价值是对未来现金流、增长、风险和资本成本的估计区间。市场价格则是边际买卖双方在当前信息、仓位与情绪下形成的成交结果。

### 4. 好公司不等于好投资

好公司如果买得过贵，也可能产生很差的投资回报；普通公司如果价格极低，也可能产生较高回报。投资需要同时判断企业质量与价格。

### 5. 风险管理优先于收益最大化

长期复利最怕永久性损失、杠杆爆仓和大额回撤后被迫退出。风险控制不是保守，而是确保你还能留在牌桌上。

> 本手册用于学习与研究方法，不构成对任何证券、基金或其他资产的买卖建议。
