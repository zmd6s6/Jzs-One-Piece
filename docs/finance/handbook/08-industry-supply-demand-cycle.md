# 行业研究：供给、需求、库存与周期

## 1. 行业研究首先回答价值链

在看龙头公司之前，先画产业链：上游提供什么，中游加工什么，下游谁付钱，终端需求来自哪里。

每一层都要标出：产品、客户、主要成本、定价方式、竞争格局和产能扩张难度。

## 2. 需求

需求要拆成可量化来源。比如动力电池需求可以继续拆到新能源汽车销量、单车带电量、不同地区渗透率；铜需求可拆到电网、地产、制造、新能源等。

不要用“行业空间很大”代替需求分析。需要问：

- 当前真实消费量多少？
- 增量来自哪里？
- 增速能持续多久？
- 价格变化会不会抑制需求？
- 是否存在替代品？

## 3. 供给

供给研究要区分：

- 名义产能；
- 有效产能；
- 实际产量；
- 在建产能；
- 规划产能。

规划产能不是即时供给。矿山、化工厂、晶圆厂和电池厂从公告到达产可能经历审批、建设、爬坡和良率问题。

## 4. 供需缺口

最简化：`库存变化 ≈ 供给 - 需求`。

供给持续大于需求通常导致累库和价格压力；需求超过供给通常导致去库和涨价压力。现实中还要考虑贸易、季节性和隐性库存。

## 5. 库存

库存是供需结果，也是预期行为。

去库可能来自需求变强，也可能来自供给中断；累库可能来自需求弱，也可能是企业为旺季提前备货。

因此不要看一周库存数据就宣布周期反转。更应该观察连续趋势、季节性和价格是否同步确认。

## 6. 成本曲线

商品行业里，不同生产商的单位成本不同。把全球或全行业产能按成本从低到高排序，就得到成本曲线。

当价格下跌时，高成本产能更容易亏损、减产或退出；低成本生产商更能穿越周期。因此成本位置往往比单一产量更重要。

## 7. 价格如何传导到利润

企业利润大致受：`销量 × 单位售价 - 单位成本 × 销量 - 固定成本`影响。

如果公司固定成本高，产品价格小幅变化可能导致利润大幅变化，这就是经营杠杆。

同一个商品涨价，对上游资源企业可能是收入端利好，对下游加工企业却可能是成本压力。不要把“商品涨”直接等同于“产业链都涨”。

## 8. 资本开支是周期的内生驱动力

经典周期链：

`价格上涨 → 利润上升 → 企业扩产 → 新产能投放 → 供给过剩 → 价格下跌 → 利润下降 → 停止扩产/淘汰高成本产能 → 供给收缩 → 周期重新改善`。

行业最赚钱的时候，往往也是未来供给压力积累最快的时候。

## 9. 领先、同步和滞后指标

### 领先指标

订单、招标、资本开支计划、开工率、库存拐点、期货期限结构等可能领先利润。

### 同步指标

现货价格、产量、销量等。

### 滞后指标

财报利润通常滞后于行业价格和经营数据。

投资研究要尽量知道自己看的是哪一类。

## 10. 竞争格局

除了供需，还要看行业结构：

- 龙头数量；
- 市场集中度；
- 产品同质化；
- 客户议价能力；
- 供应商议价能力；
- 进入壁垒；
- 退出壁垒。

供需平衡相同的两个行业，如果一个是高度同质化价格战，另一个是寡头定价，企业利润率可能完全不同。

## 11. 产业趋势与周期位置必须分开

“新能源长期增长”属于长期趋势；“当前锂盐供给过剩、库存高”属于周期位置。两者可以同时成立。

很多投资错误来自用长期趋势否认短期供给周期，或者用短期下行否认长期产业变化。

## 12. 行业周期事实卡

| 模块 | 要记录什么 |
| --- | --- |
| 终端需求 | 量、增速、驱动 |
| 供给 | 产能、产量、新增项目 |
| 库存 | 水平、趋势、季节性 |
| 产品价格 | 现货/长协/期货 |
| 成本 | 关键原材料、行业成本曲线 |
| 利润 | 行业毛利/代表公司利润 |
| Capex | 扩产意愿与在建项目 |
| 竞争 | 集中度、价格战、壁垒 |
| 政策 | 是否改变需求/供给约束 |
| 下一步验证 | 哪3个指标最先变化 |

## 13. 周期反转需要证据组合

一个更严谨的反转框架通常需要看到若干信号共同出现，例如：

- 价格跌到高成本产能亏损；
- 扩产计划取消；
- 开工率下降；
- 库存持续去化；
- 需求数据稳定或改善；
- 盈利预期停止下修。

单一价格反弹不足以证明周期已经反转。

## 小结

行业研究的核心闭环是：`需求 → 供给 → 库存 → 价格 → 企业利润 → 资本开支 → 新供给`。长期趋势告诉你市场可能变多大，周期分析告诉你利润现在处在哪。
