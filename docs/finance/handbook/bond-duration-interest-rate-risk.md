# 为什么5—10年债券基金容易波动：久期与利率风险

同样是市场收益率上涨0.5个百分点，有的债券只跌一点，有的债券却跌好几个百分点。为什么？因为债券未来收款的时间和方式不同。

阅读前置：[市场利率为什么与债券价格反向变化](./bond-market-rates-and-pricing.md)。

## 久期是什么？

**久期（Duration）**衡量债券现金流在时间上的分布，以及债券价格对收益率变化的敏感程度。可以把它想成：“买入后，未来的钱平均要等多久才拿到，以及这些钱的现值有多怕利率变化。”

- **麦考利久期**：按未来每笔现金流现值加权计算的平均回收时间，单位为年。
- **修正久期**：用于近似衡量债券价格对到期收益率变动的敏感度，是讨论债券基金利率风险时特别常用的指标。

通常在其他条件相同的情况下，收到本金和利息越晚，价格对利率变化越敏感。所以长期限债券通常比短期限债券更容易出现较大的价格波动。

注意：**剩余期限≠久期**。例如一只“投资5—10年剩余期限债券”的基金，不意味着基金修正久期一定是5年或10年；票息、持仓结构、回购杠杆等都会影响风险暴露。

## 一个够用的计算公式

在收益率变化不大、现金流与其他风险大体不变时：

```text
债券价格变动百分比 ≈ -修正久期 × 市场收益率变动幅度
```

其中0.5个百分点要写成0.005，而不是0.5。公式前面的负号代表**收益率和价格反向变化**。

例如，假设某债券组合修正久期为6年，投资金额3000元：

| 同类收益率变化 | 估算价格涨跌 | 3000元持仓的估算市值变化 |
| --- | ---: | ---: |
| 下降0.50个百分点 | 约+3.0% | 约+90元 |
| 上升0.25个百分点 | 约-1.5% | 约-45元 |
| 上升0.50个百分点 | 约-3.0% | 约-90元 |
| 上升1.00个百分点 | 约-6.0% | 约-180元 |

以上**只是价格敏感度模拟**，没有计入利息收入、费用、信用风险、收益率曲线形态和凸性，不是任何具体基金的收益预测。

## 为什么这只是近似值？

债券价格和收益率之间并不是精确直线关系。当收益率变化很大时，需要考虑**凸性（Convexity）**——价格变化曲线的弯曲程度。不同期限的收益率还可能涨跌不一，基金实际持仓也可能改变。

因此，不能把“修正久期6”机械理解为“未来一年必然涨跌6%”。久期主要用来测算**某一时点对利率冲击的敏感度**，并不单独决定一年的总回报。

## 利率上涨是不是永远坏事？

对于**已经持有的债券**，收益率突然上升通常带来即时的估值损失；但之后到期、付息和新增资金再投资时，较高的市场收益率可能提高未来持有收益。

这形成两种相反力量：

1. **价格效应**：收益率上升，旧债价格先跌。
2. **再投资效应**：之后以更高收益率买债，未来现金流积累潜力提高。

但如果基金持续维持长久期，后续再次加息仍可能造成新的价格损失；并没有“持有满久期就保证回本”的结论。

## 决策时如何使用久期？

1. 先确认资金用途：半年内要用的钱，无法承受长债短期回撤时，不宜仅为了历史收益率而配置长久期基金。
2. 看基金定期报告中的**组合久期、券种、债券剩余期限、杠杆和信用等级**，不要只看基金名字。
3. 对利率上升0.25、0.50或1个百分点做压力测试，确认亏损金额能否承受。
4. 结合当下债券到期收益率判断潜在利息缓冲，注意收益率不是保底收益。
