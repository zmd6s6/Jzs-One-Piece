# 企业质量：ROE、ROIC、现金流与护城河

## 1. “好公司”到底好在哪里

高质量企业通常同时具有真实客户需求、合理利润率、高资本回报、不过度依赖负债、现金流好、可持续再投资机会、竞争优势和合理资本配置。

真正的问题是：**公司能否在较长时间内，以高于资本成本的回报率持续扩大价值？**

## 2. ROE：股东资金的回报

`ROE = 净利润 / 平均股东权益`。

高ROE可能来自利润率高、资产周转快，也可能来自杠杆高。杜邦分析的直觉是：`ROE ≈ 净利率 × 资产周转率 × 权益乘数`。

因此高ROE不自动等于高质量。

## 3. ROIC：经营资本的回报

ROIC关注企业使用股权和债务资本开展经营后获得的税后经营回报。概念上可理解为：`ROIC = 税后经营利润 / 投入经营资本`。

不同数据源口径会不同，不要制造精确到小数点的假象。核心是问：公司每再投入1元资本，长期能创造多少经营利润？

## 4. 为什么ROIC比增长本身更重要

企业可以通过烧钱扩张收入，却不一定创造价值。两家公司收入都从100亿做到200亿，一家新增资本30亿并新增利润8亿，另一家投入150亿只新增利润5亿，经济质量完全不同。

增长只有在新增资本回报高于资本成本时才真正创造价值。

## 5. 再投资率与增长

长期增长能力可以粗略理解为：`增长能力 ≈ 再投资率 × 新增资本回报率`。

高ROIC但没有再投资机会的公司可能适合分红；低ROIC公司即使疯狂扩张，也可能摧毁价值。

极稀缺的组合是：`高ROIC + 大量可重复再投资机会 + 长时间维持`。市场往往因此给予高估值。

## 6. 自由现金流与资本强度

两个公司净利润都是100亿，如果A维持业务只需资本开支10亿，B需要90亿，A通常有更多现金可以分红、回购、并购或继续投资。

但“轻资产永远优于重资产”同样错误。重资产行业若有成本优势、进入壁垒和高资本回报，也能创造巨大价值。关键仍是资本投入后的回报。

## 7. 护城河必须落到证据

“品牌强”“技术领先”“龙头”只是主张。一个可验证护城河需要回答：竞争对手为什么难复制？客户为什么不切换？企业是否因此获得超额资本回报？优势能持续多久？

### 成本优势

证据可以是单位成本低、资源禀赋、规模摊薄、工艺和供应链优势。

### 品牌与定价权

证据可以是长期高毛利、提价后销量韧性、高复购、渠道议价能力。

### 网络效应

用户越多，产品对其他用户越有价值，常见于支付、社交和平台。注意“规模大”不等于网络效应。

### 切换成本

可能来自数据迁移、培训、认证、业务流程嵌入和监管批准。

### 稀缺资产/牌照

如高品位矿山、特殊地理资源或稀缺牌照。

## 8. 市场份额不是护城河本身

高份额可能来自补贴、低价抢量或暂时领先。如果高份额没有转化为更高利润率、更低成本、更高资本回报或更强客户粘性，它可能只是规模，不是护城河。

## 9. 管理层资本配置

管理层可以把现金用于主营再投资、并购、偿债、分红、回购或持有现金。正确选择取决于每个选项的预期回报。

股票低估时回购可能有效，高估时回购可能浪费资金；主营ROIC很高时过度分红可能错失增长；没有好项目时强行并购可能摧毁价值。

## 10. 高增长公司的质量检查

- 增长来自价格还是销量？
- 是否依赖补贴？
- 是否依赖应收扩张？
- 是否需要大额资本开支？
- 获客成本是否上升？
- 市场份额提升是否伴随利润恶化？
- 新增资本回报是否下降？
- 行业需求是否真能支撑扩产？

## 11. 高质量企业也会变坏

护城河会被技术替代、监管、消费习惯、渠道迁移、竞争创新、原料结构或资本配置失误破坏。企业质量是动态判断，不是永久标签。

## 12. 企业质量事实卡

| 维度 | 核心问题 |
| --- | --- |
| 商业模式 | 谁付钱、为什么付钱？ |
| 毛利/净利 | 利润率是否稳定？ |
| ROE/ROIC | 高回报来自经营还是杠杆？ |
| FCF | 利润能否转为现金？ |
| 资本开支 | 增长需要多少投入？ |
| 再投资 | 新投入还能维持高回报吗？ |
| 护城河 | 有什么可验证证据？ |
| 资本配置 | 管理层如何使用现金？ |
| 资产负债表 | 逆风期能否生存？ |
| 风险 | 哪个变化最可能破坏逻辑？ |

## 小结

企业质量可以浓缩成一个问题：**它能否长期以高于资本成本的回报率，把资本投入可持续的竞争优势中，并最终转化为股东现金流？**
