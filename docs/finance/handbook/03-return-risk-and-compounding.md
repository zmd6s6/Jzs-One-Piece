# 收益、风险、复利与回撤

## 1. 投资不能只比较终点收益

两个策略都从100万变成150万，路径可能完全不同。一个最大回撤10%，另一个中途先跌到40万再反弹。现实中很少有人能无条件承受后者。

真实结果取决于最终收益、波动路径、回撤、流动性、杠杆以及你的心理和现金流约束。

## 2. 简单收益率

`收益率 = (期末价值 - 期初价值 + 期间现金分配) / 期初价值`

100元买入、110元卖出是10%；若期间拿到3元分红，总回报是13%。分析基金和指数时必须确认是否包含分红再投资。

## 3. 涨跌百分比不对称

从100跌到50是-50%，从50回到100需要+100%。

`回本涨幅 = 1 / (1 - 跌幅) - 1`

| 跌幅 | 回本所需上涨 |
| ---: | ---: |
| 10% | 11.1% |
| 20% | 25.0% |
| 30% | 42.9% |
| 40% | 66.7% |
| 50% | 100% |
| 70% | 233.3% |

这解释了为什么控制巨大损失对长期复利极其重要。

## 4. 复利

`终值 = 本金 × (1 + 收益率)^年份`。

复利真正依赖的不是偶尔一年暴涨，而是持续时间、几何平均收益率、成本税费、避免毁灭性亏损以及能否持续执行。

## 5. 算术平均与几何平均

第一年+50%，第二年-50%。算术平均收益率是0%，但100×1.5×0.5=75，实际两年亏25%。

长期投资应更多关注复合收益而非简单平均。

## 6. CAGR

`CAGR = (期末价值 / 期初价值)^(1/年数) - 1`。

它回答的是：如果每年以固定复合速度增长，需要多少年化才能从起点走到终点。

## 7. 最大回撤

`Drawdown = 当前价值 / 历史最高价值 - 1`。

序列100→120→110→90→85→130，峰值120、谷值85，最大回撤约-29.2%。

相比波动率，很多投资者的真实痛感更接近：账户从高点亏了多少、持续多久、多久恢复前高、是否在最差时需要现金。

## 8. 波动不是唯一风险

真实投资至少包括：

- **永久性资本损失**：破产、商业模式失效、欺诈或严重稀释；
- **流动性风险**：需要卖时卖不掉；
- **杠杆风险**：最终方向正确，但中间先被强平；
- **估值风险**：好公司买得太贵；
- **行为风险**：恐慌割肉和FOMO追高。

“长期持有能消除风险”不成立。长期不会消除错误资产和错误价格带来的永久损失。

## 9. 风险与不确定性

最危险的状态之一是“不知道自己不知道什么”。稳健分析不是假装精确，而是承认模型误差并保留安全边际。

## 10. 风险预算

仓位管理的核心不是看好程度，而是：**如果我错了，账户最多允许损失多少？**

例：账户100万，单一投资最大允许损失3万；若一个合理压力情景是亏40%，则粗略仓位上限约 `3万/40%=7.5万`，即7.5%。

最坏情景本身无法精确预测，所以风险预算是约束工具，不是数学真理。

## 11. 分散的是风险因子，不是股票代码

5家锂矿股+3家新能源材料股+2只新能源ETF看起来有10个持仓，但核心风险可能都来自锂价、新能源需求、成长估值和资本开支周期。

真正分散要看收益驱动因素是否独立。

## 12. 胜率、盈亏比与期望值

策略A：胜率40%，赢一次+30，输一次-10，单次期望=`0.4×30-0.6×10=+6`。

策略B：胜率80%，赢一次+5，输一次-30，单次期望=`0.8×5-0.2×30=-2`。

所以高胜率不等于赚钱。

## 13. 风险管理优先级

1. 避免爆仓和永久性损失；
2. 控制组合回撤；
3. 保证流动性；
4. 再优化收益率。

## 小结

长期财富增长更接近：`复合收益率 × 可持续时间 × 不被迫退出`。风险管理的目的，是让复利有机会持续足够久。
