# 直接买债券与买债券基金，真正的区别是什么？

假设你准备把一笔钱放进相对稳健的债券类资产：一种办法是自己买一张债券，另一种是买一只“纯债基金”。两者看起来都在赚债券利息，为什么有人说前者可以“等到期”，后者却不能？

## 一句话区分

- **单只债券**：你直接持有发行人的债权，按合同收取利息和到期本金（前提是发行人履约）。
- **债券基金**：你持有的是基金份额，基金按投资目标持有和交易多只债券；你的资产价值跟随基金净值变化，普通开放式债券基金没有统一的到期还本承诺。

生活类比：买单只债券像自己借钱给某个机构，约好还款日期；买债券基金像把钱交给专业管理团队，由它建立并持续维护一个“借款合同组合”。

## 放在一起比较

| 对比 | 单只固定利率债券 | 普通开放式债券基金 |
| --- | --- | --- |
| 你持有什么 | 直接债权 | 基金份额，间接承担底层债券风险 |
| 现金流 | 按债券条款收息、到期偿还面值 | 基金持债收息；是否向持有人分红取决于基金分红安排 |
| 到期日 | 通常有明确的债券到期日 | 基金通常持续运营，无统一到期日 |
| 如何退出 | 持有至到期或提前卖出（能否交易视品种而定） | 按基金合同赎回或交易，价格随净值变化 |
| 利率风险 | 中途出售时价格受利率影响 | 持续体现在净值变化中 |
| 信用风险 | 集中于所买发行人 | 可以分散个券风险，但不能消除共同风险 |
| 管理与成本 | 自己选择券种、期限、价格及交易方式 | 支付管理、托管等费用，可能有申购、赎回和销售服务费用 |
| 是否保本 | 不保本，发行人可能违约，买入价也可能偏离面值 | 不保本，也无固定回本日期 |

特别注意：直接买债券不等于所有品种都“保本”。信用风险、买价高于面值、通胀、提前卖出和复杂条款，都可能影响最终结果。

## 例子一：直接买债券

假设你按**面值1000元**买入一只普通固定利率债券，剩余5年，每年付息30元，到期偿还1000元本金，忽略税费和违约。

- 途中市场利率上升，债券的**市场交易价格**可能降到950元。这是当时卖出的参考价格，不代表合同本金自动变为950元。
- 如果你无需提前卖出，并且发行人按约兑付，那么到期可收回1000元本金，同时按合同收到各年的利息。

如果最初以高于面值的价格买入，持有到期时按面值收回本金可能带来**价格损失**；因此实际到期收益要基于买入价格计算，不能只看票息。

## 例子二：买债券基金

假设你投入1000元买普通开放式债券基金。基金今天持有A、B、C三只债券。A到期后收回的本金，基金可能继续投入D债券；以后B和C到期也类似。

所以基金持有的债券会持续换新，基金并不会因为你个人持有5年，就按你买入那天的1000元“兑付本金”。

你赎回时通常按基金合同规定的**赎回净值**计算金额，扣除适用费用；价格可能高于也可能低于1000元。

## 一个容易误解的情况：指数基金也会换券

例如“5—10年期限政策性金融债指数基金”，指数规则可能要求持仓债券的剩余期限保持在某个区间。随着时间推移，旧券逐渐不再符合期限要求，组合可能卖出旧券、买入新券。

因此，不应把“基金主要买5—10年债券”理解为“我持有基金5—10年就自动收回本金”。

## 哪种更适合什么目标？

- **需要匹配确定日期的用钱计划**：可以研究合适期限、信用风险和交易渠道的单只债券，重点是合同现金流及到期安排。
- **需要长期、分散且省去自己管理多个债券的工作**：可研究债券基金，重点是组合久期、券种、费用、信用和波动。
- **短期可能随时取钱**：不能把5—10年长久期债券基金当成货币基金或存款；要考察赎回规则和可能的净值回撤。

市场上还有**定期开放债券基金、持有期债券基金、目标到期债券基金**等特殊结构，其开放安排和投资策略与普通开放式基金不同。具体以基金合同、招募说明书为准。
