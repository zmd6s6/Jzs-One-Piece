# 投资组合、仓位与风险预算

## 1. 组合不是把多个好资产放在一起

投资组合要解决的是：单个判断错误时不致毁掉整体账户，以及多个资产在不同环境下如何共同工作。

## 2. 资产配置先于个股选择

长期回报和回撤很大程度取决于股票、债券、现金、商品等大类资产暴露。个股研究再强，也无法消除组合层面的系统风险。

## 3. 相关性

两个资产平时走势不同，不代表危机时仍独立。极端压力下相关性往往上升。

所以分散不应只看历史相关系数，还要问它们是否暴露于同一风险因子。

## 4. 风险因子

常见因子包括：

- 经济增长；
- 利率；
- 通胀；
- 信用；
- 商品价格；
- 汇率；
- 科技成长估值；
- 中国/美国等区域政策。

持有多只股票，但全部对同一因子敏感，仍是集中组合。

## 5. 仓位上限

单一持仓上限应结合：

- 资产最坏合理情景；
- 流动性；
- 估值风险；
- 商业模式不确定性；
- 与其他持仓相关性；
- 个人现金流与心理承受力。

不是“越看好越重仓”。

## 6. 风险预算法

设账户100万，允许某笔判断错误最多损失账户2%，即2万。若压力情景预计该资产可能跌35%，粗略仓位是 `2万/35%≈5.7万`。

这只是约束思维。真正尾部风险可能大于35%，因此不能把模型当保护伞。

## 7. 初始仓与加仓

一个实用原则是让仓位随着证据增加，而不是随着亏损增加。

### 合理加仓

- 基本面验证更强；
- 风险下降；
- 估值更有吸引力；
- 原假设未破坏。

### 危险加仓

- 只因为亏了很多，想降低成本；
- 不重新检查行业和盈利；
- 反复扩大原本错误判断。

## 8. 再平衡

资产涨跌后权重会偏离目标。再平衡是把组合拉回预定风险水平。

它不是自动“卖涨买跌”的万能策略；如果基本面发生结构变化，目标权重本身也应该重新评估。

## 9. 现金仓位

现金可以承担：

- 日常流动性；
- 应急资金；
- 降低组合波动；
- 为未来机会保留选择权。

如果生活应急资金和投资资金混在一起，市场下跌时容易被迫卖出。

## 10. 杠杆

杠杆的危险在于路径依赖。最终方向正确也不够，中间波动可能触发追加保证金或强制平仓。

长期个人投资体系若没有明确专业需求，应把“避免不可控杠杆”放在非常高优先级。

## 11. 集中与分散

集中投资可以放大正确认知的收益，也放大未知风险。只有在：

- 深度理解；
- 信息和分析优势真实存在；
- 资产流动性足够；
- 最坏损失可承受；
- 没有致命相关暴露

的前提下，集中才有讨论空间。

## 12. 组合压力测试

至少模拟：

- 股票市场整体-30%；
- 最大持仓-50%；
- 行业主题资产同时-40%；
- 利率突然上升；
- 人民币/美元明显变化；
- 需要立即提取一笔生活现金。

如果任一场景会迫使你卖出不想卖的资产，组合风险可能过高。

## 13. 组合仪表盘

| 项目 | 建议记录 |
| --- | --- |
| 股票/债券/现金占比 | 大类风险 |
| 单一最大仓位 | 集中度 |
| 前5大持仓占比 | 组合集中 |
| 行业暴露 | 同周期风险 |
| 地区/币种暴露 | 汇率和区域风险 |
| 预期流动性需求 | 被迫卖出风险 |
| 最大历史/压力回撤 | 承受能力 |

## 小结

仓位不是观点的情绪表达，而是风险预算。一个好的组合首先要做到：**即使若干判断错了，你仍有资本、现金和心理空间继续做下一次正确决策。**
