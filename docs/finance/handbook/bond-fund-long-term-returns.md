# 债券基金长期为什么可能向上，为什么不能照搬历史收益？

打开一只债券基金的长期累计净值图，可能看到一条缓慢向上的曲线。但基金又没有统一的到期还本日，市场利率一涨还可能跌。**长期上涨的钱到底从哪里来？**

答案是：**债券组合持续产生利息收入，经过持有、再投资和资产定价，可能形成长期总回报；但任何单一持有期都不保证上涨。**

阅读前置：[债券与债券基金的区别](./bond-vs-bond-fund.md)、[市场利率与债券定价](./bond-market-rates-and-pricing.md)。

## 债券基金收益的四个来源和成本

把基金总回报拆开思考：

1. **利息收入**：底层债券按合同持续付息，是主要的长期收益基础之一。
2. **债券价格变化**：市场到期收益率下降可能使已持有债券涨价；反过来，收益率上升可能使它们跌价。
3. **到期、付息与再投资**：收到利息或本金后按新的市场收益率买债；较高的新收益率可能改善之后的收益潜力，较低收益率则相反。
4. **其他影响**：组合换券、期限结构变化（例如骑乘与滚降效应）、信用损失、杠杆融资成本、交易成本、管理托管费用等，都会改变净结果。

所以，**长期收益不是“每天领固定利息”那么简单**。某一年价格损失超过利息收入，基金总回报就可能为负。

## 假设收益每年3%，复利为什么能累积？

如果初始投资10000元，每年都恰好实现3%的**净总回报**，而且分红全部再投资：

```text
终值 = 10000 × (1 + 3%) ^ 年数
```

| 时间 | 假设账户价值 |
| --- | ---: |
| 起点 | 10000元 |
| 第1年 | 10300元 |
| 第5年 | 约11593元 |
| 第10年 | 约13439元 |

这里的3%只是**数学教学假设**，不是债券基金承诺的收益率或预测收益率。真实基金每年收益不同，可能连续数月甚至一年以上亏损；复利并不能消除本金损失。

## 为什么过去十年的曲线很漂亮，未来却不一定？

当市场到期收益率持续下降时，基金通常同时享受：

- 债券持有期的利息收益；
- 旧债券估值上升带来的**资本利得**。

于是过去一段时期基金的实际收益率，可能显著高于当时债券原本的利息水平。可是债券收益率不可能无限下降。

**未来回报的起点更依赖当前持仓的收益率，而不是过去基金净值涨了多少。** 还要看信用利差、持仓久期、费用、交易和未来利率路径。当前到期收益率也不等于未来基金年化收益率。

## 利率上升，会不会让长期逻辑失效？

假设一个债券组合修正久期为6年，市场收益率一次上升0.5个百分点。若其他条件不变，价格可能立即下跌约3%；但以后新买入债券的收益率可能更高。

这是“**即期估值损失**”和“**未来再投资收益潜力改善**”并存的结果。后者能否弥补前者，取决于未来利率路径、持有期限、基金是否维持长久期、信用及费用等。**不存在“只要持有久期对应的年数就一定回本”的保证。**

进一步解释价格敏感度，见[久期与利率风险](./bond-duration-interest-rate-risk.md)。

## 我看的到底是单位净值，还是累计净值？

这三个指标不一样：

- **单位净值**：某日每份基金的净资产价值，通常是赎回金额计算的基础之一。
- **累计净值**：通常为当日单位净值加上历史累计每份现金分红，用来直观看历史分红记录；不完全等同于把分红复投后的收益曲线。
- **复权净值 / 分红再投资后的总回报序列**：按照约定方式处理历史分红，更适合跨分红日期比较投资回报，但仍需核对统计口径。

例如一份基金分红前净值1.10元，分红0.10元，除息后其他条件不变，单位净值理论上变为1.00元，持有人多拿0.10元现金。**净值下降不等于凭空亏了0.10元，分红也不是额外赠送的利润。**

判断个人真实收益，需按**自己的买入日期、成交金额、持有份额、分红方式、赎回金额和费用**计算，不能把“成立以来累计收益率”当成现在买入后的预期收益。

## 长期投资债券基金，真正应该看什么？

| 问题 | 为什么重要 |
| --- | --- |
| 底层买什么债？ | 决定信用风险与收益来源，政策性金融债与企业信用债不同 |
| 当前组合收益率怎样？ | 决定持有收益的基础，历史表现不能替代 |
| 久期多长？ | 决定利率变化时可能出现多大净值波动 |
| 有没有信用集中或杠杆？ | 关系到额外收益与损失风险 |
| 管理、托管、销售服务和交易成本多少？ | 费用会长期侵蚀低收益资产的净回报 |
| 我的钱何时需要使用？ | 影响能否承受阶段性回撤与赎回压力 |
| 这只基金与股票、现金的风险相关性如何？ | 长期资产配置看的是整个组合而非单只基金名次 |

### A类与C类顺便怎么理解？

同一基金的A、C份额通常持有相同投资组合，但**费用收取结构不同**。A类常见前端申购费、无销售服务费；C类通常不收前端申购费，但持续按年计提销售服务费。持有较久、申购费有折扣时，A类有可能更省钱，但应根据**该基金最新费率和实际申购折扣**核算；赎回费也可能随持有期变化。

## 最后形成一句判断

> 债券基金的长期逻辑，是赚取底层债券组合未来的净持有收益，同时承担利率、信用和流动性变化造成的价格波动；历史累计净值向上，不是未来按同样斜率增长的承诺。
