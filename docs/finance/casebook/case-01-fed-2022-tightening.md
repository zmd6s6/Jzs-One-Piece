# 案例01：2022 美联储快速加息

## 案例目的

训练一个核心能力：看到“加息”时，不直接跳到“股票跌”，而是拆解政策为什么发生、利率如何传导、哪些资产最敏感、市场是否已经提前定价。

## 1. 已知事实

美联储官方历史表显示，2022年联邦基金目标区间经历了快速上调：

| 日期 | 调整 | 目标区间 |
| --- | ---: | --- |
| 2022-03-17 | +25bp | 0.25%–0.50% |
| 2022-05-05 | +50bp | 0.75%–1.00% |
| 2022-06-16 | +75bp | 1.50%–1.75% |
| 2022-07-28 | +75bp | 2.25%–2.50% |
| 2022-09-22 | +75bp | 3.00%–3.25% |
| 2022-11-03 | +75bp | 3.75%–4.00% |
| 2022-12-15 | +50bp | 4.25%–4.50% |

也就是说，一年内政策利率环境从接近零快速切换到明显限制性区间。

## 2. 为什么这对估值重要

成长股的大量价值来自较远未来现金流。折现率上升时，远期现金流现值下降得更明显。

简化例子：假设10年后收到100元。

- 折现率3%：现值约74.4元；
- 折现率8%：现值约46.3元。

现金流本身没有变化，仅折现率变化就足以显著改变今天的价值。

## 3. 但不能只看折现率

加息还通过真实经济影响盈利：融资成本上升、房地产和耐用品需求降温、企业资本开支可能放缓。

所以股票价格可能同时承受：

`估值倍数下降 + 盈利预期下修`。

但银行、保险、能源、现金流稳定价值股等资产的敏感度可能不同，不能用一个结论覆盖所有行业。

## 4. 为什么市场可能在第一次加息前就跌

金融市场交易未来。只要投资者开始预期未来政策路径发生变化，长期利率和估值就可能提前调整。

因此正式加息日并不是唯一信息点。还要看：

- CPI/PCE；
- 就业和工资；
- 美联储沟通；
- 国债收益率；
- 市场对未来利率路径的定价。

## 5. 当时可以建立的可验证假设

例如：

**假设A**：如果通胀持续高于目标且就业强，美联储将维持限制性政策更久。

验证指标：核心通胀、失业率、工资、FOMC点阵和声明。

**假设B**：高估值、远期现金流占比高的资产对实际利率上升更敏感。

验证指标：真实利率、长端收益率、成长/价值相对估值。

## 6. 这个案例不能推出什么

- 不能推出“任何加息周期股票都必跌”；
- 不能推出“降息股票必涨”；
- 不能只根据政策利率判断某个行业；
- 不能忽略市场已经提前定价的部分。

## 7. 你应该留下的框架

`通胀/就业 → 央行反应函数 → 政策利率预期 → 长端利率与金融条件 → 企业盈利 + 折现率 → 资产价格`。
