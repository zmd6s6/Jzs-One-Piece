# 金融投资案例库

案例的目的不是告诉你“当时应该买什么”，而是训练如何把事实放进统一框架。所有案例都使用历史公开资料，避免把后见之明包装成当时可确定的答案。

## 案例阅读规则

每个案例都按四层阅读：

1. **事实**：当时公开数据是什么；
2. **机制**：这些数据如何进入现金流、风险或估值；
3. **可验证假设**：当时可以持续跟踪什么；
4. **边界**：案例不能证明什么。

如果一个案例只能让你记住“某公司很好/很差”，那就没有学到真正可迁移的东西。
