# 案例05：恒生科技指数——从指数规则理解ETF

## 案例目的

训练一个非常重要的习惯：买ETF之前先研究指数，不要只看ETF名字。

## 1. 指数是什么

恒生指数公司对恒生科技指数的官方描述是：代表经筛选后最大30间与科技主题高度相关的香港上市公司。

这意味着它不是“整个港股科技行业”，而是经过资格筛选、排序和权重规则构成的组合。

## 2. 为什么指数规则决定你的暴露

官方方法文件显示，指数有固定成分数量、定期审议和再平衡，并按自由流通市值加权，同时设置单一成分权重上限。

因此投资者实际上承担的是：

- 大型科技公司风险；
- 香港市场风险；
- 中国互联网/科技政策与盈利风险；
- 市值加权带来的大公司集中；
- 指数季度调整规则；
- 若通过人民币跨境ETF持有，还可能有汇率、额度和交易时差因素。

## 3. “30只股票”不代表高度分散

如果前几大成分来自相似商业模式或同一宏观风险因子，组合仍可能高度相关。

分析时要看：

- 前十大权重合计；
- 行业分布；
- 盈利型公司与亏损成长公司比例；
- 平台互联网、硬科技、新能源等暴露；
- 单一公司权重上限。

## 4. 指数会自己变化

指数定期调整意味着你今天买的“恒生科技”并不是永久固定的30家公司。弱势公司可能被剔除，新公司进入。

这既是指数自我更新的优点，也意味着历史回测中的指数成分与今天不同，存在成分变化效应。

## 5. ETF还多一层产品结构

即便指数本身理解清楚，还要检查具体ETF：

- 跟踪误差；
- 管理费；
- 基金规模；
- 成交量与价差；
- 是否QDII/跨境；
- 折溢价；
- 分红处理。

指数好不等于任何跟踪它的基金都一样。

## 6. 一个实用ETF分析模板

1. 指数定义；
2. 选样范围；
3. 成分数量；
4. 加权方式；
5. 权重上限；
6. 调仓频率；
7. 前十大成分；
8. 行业集中；
9. 估值和盈利特征；
10. ETF费用、规模和折溢价。

## 7. 这个案例不能推出什么

- 不能从指数规则推出未来涨跌；
- 不能因为“科技长期成长”忽略估值；
- 不能因为ETF有30家公司就认为风险低；
- 不能把指数历史收益直接当未来收益。
