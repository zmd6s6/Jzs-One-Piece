# 案例03：贵州茅台 2023——现金流与资本配置

## 案例目的

学习如何识别一种与重资产制造完全不同的经济模型：高毛利品牌资产、强盈利、较低维持性资本需求和大额现金返还。

## 1. 2023年公开数据

贵州茅台2023年年报披露：

- 营业总收入约 **1505.60亿元**；
- 归属于上市公司股东净利润约 **747.34亿元**；
- 经营活动产生的现金流量净额约 **665.93亿元**；
- 全年现金分红合计约 **565.5亿元**，约占2023年归母净利润 **75.67%**。

年报主营业务分析表中的营业收入约1476.94亿元，与“营业总收入”口径并不完全相同。这个细节本身就是一个重要提醒：**比较财务数据必须确认口径。**

## 2. 从利润率看商业模式

用主营营业收入1476.94亿元和营业成本118.67亿元做粗略计算，可以直观看到其产品毛利空间很高。

但“高毛利=护城河”仍然不是完整论证。需要继续问：

- 为什么消费者愿意支付高价格？
- 供给是否受生产周期和品牌控制？
- 渠道是否稳定？
- 提价是否会损害长期需求？
- 品牌和稀缺性能否持续？

## 3. 利润与现金流

2023年经营现金流低于归母净利润，但仍处于很高绝对水平。不能用单年 `CFO/净利润 < 1` 就判断盈利质量差。

白酒企业可能受合同负债、税费支付、经销商回款节奏等影响，需要看多年趋势和资产负债表变化。

正确动作是：发现差异 → 查现金流项目和营运资本 → 解释，而不是直接打分。

## 4. 分红体现资本配置问题

高分红本身不创造额外价值，但如果企业：

- 主业已经产生大量现金；
- 维持业务不需要把全部利润重新投入；
- 没有足够多高回报项目；

那么把多余现金返还股东可能是合理资本配置。

反过来，高成长且ROIC极高的公司，如果把几乎全部现金分红，可能牺牲高回报再投资机会。

## 5. 研究高质量消费公司时的固定问题

1. 品牌能否持续提价？
2. 销量增长来自真实消费还是渠道库存？
3. 毛利率为何长期稳定？
4. 渠道改革是否影响利润分配？
5. 现金流与利润是否长期匹配？
6. 剩余现金如何配置？
7. 当前价格已经隐含多少长期增长？

## 6. 最容易犯的错误

看到高ROE、高毛利、强品牌就直接得出“任何价格都值得买”。

高质量企业常常因为所有人都认可其质量而获得高估值。最终投资回报仍取决于买入价格与未来实际增长的差异。

## 7. 可迁移知识

企业质量和投资价值必须分两层：

`商业模式质量 → 现金流质量 → 资本配置质量`，然后再进入 `当前估值 → 隐含预期 → 安全边际`。
