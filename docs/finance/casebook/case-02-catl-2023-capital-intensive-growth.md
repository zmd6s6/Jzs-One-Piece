# 案例02：宁德时代 2023——高增长与资本密集度

## 案例目的

学习为什么“营收增长很快”仍不足以判断制造业企业质量。对重资产成长企业，必须同时看固定资产、产能利用率、资本开支、减值和行业供需。

## 1. 年报中的关键事实

宁德时代2023年年度报告披露，2023年度营业收入约 **4009.17亿元**，同比增长 **22.01%**。

截至2023年末，公司固定资产账面价值约 **1153.88亿元**。年报关键审计事项还涉及固定资产和无形资产减值，并明确提到审计中会了解产能利用率变化和设备闲置情况。

这些信息组合在一起，比单纯的收入增速更有研究价值。

## 2. 为什么固定资产很重要

电池制造不是纯软件业务。扩张需要厂房、设备和大量供应链资本。

扩产的财务路径大致是：

`现金/融资 → 在建工程 → 固定资产 → 投产 → 折旧进入成本 → 销量与毛利决定资本回报`。

如果需求和利用率达到预期，固定资产帮助扩大收入；如果需求低于预期，企业可能同时面临：

- 设备闲置；
- 折旧压力；
- 价格竞争；
- 资产减值；
- 新增资本ROIC下降。

## 3. 为什么“行业长期增长”不够

新能源汽车长期渗透率提高，与电池产业某一时点是否产能过剩是两个问题。

长期需求增长可能成立，但如果全行业提前建设过多产能，短中期仍可能出现：

`产能增速 > 需求增速 → 利用率下降 → 价格竞争 → 利润率承压`。

这就是长期产业趋势与周期位置必须分开。

## 4. 财报应该继续追哪些数据

分析类似制造业公司时，可连续3～5年记录：

- 营业收入与销量；
- 毛利率；
- 固定资产和在建工程；
- 资本开支；
- 产能和产能利用率；
- 存货；
- 经营现金流；
- 自由现金流；
- 资产减值；
- 单位产品售价和成本。

## 5. 一个真正可证伪的投资假设

错误：`新能源长期一定增长，所以电池龙头长期一定涨。`

更严谨：`如果终端需求保持增长、行业新增产能放缓、公司利用率维持高位且单位成本继续下降，则新增资本仍可能维持较高回报。`

这个假设可以被产能、利用率、价格、毛利率和ROIC逐季验证。

## 6. 这个案例不能推出什么

- 不能从减值直接推出公司经营恶化；
- 不能从收入增长直接推出股票低估；
- 不能从行业长期增长直接推出所有扩产都有高回报；
- 不能用单一年报判断完整产业周期。

## 7. 可迁移知识

研究任何重资产成长公司，都要把“增长”写成：

`需求增长 × 市占率 × 价格 → 收入`，再继续检查 `资本投入 → 利用率 → 折旧/成本 → ROIC/FCF`。
