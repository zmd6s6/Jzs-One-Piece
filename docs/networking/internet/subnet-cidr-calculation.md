# 为什么 192.168.1.10/24 和 /27 不一样

## 先看一个现象
两台设备 IP 看着相邻，`192.168.1.10/27` 与 `192.168.1.40/27` 却不能直接按同网段通信。因为后缀 `/27` 控制“网络位”数量。

## 定义与算法
IPv4 是 32 位地址。`/27` 表示前 27 位是网络前缀，后 5 位是主机位；块大小为 `2^(32-27)=32` 个地址，最后一段按 32 分组。

```text
192.168.1.10/27 → 192.168.1.0/27
网络地址  192.168.1.0
广播地址  192.168.1.31
常见可用主机地址 192.168.1.1 ~ 192.168.1.30
192.168.1.40/27 → 192.168.1.32/27（另一个子网）
```

一个子网的网络地址由“IP 与子网掩码逐位 AND”得到。`/24` 掩码是 `255.255.255.0`；`/27` 是 `255.255.255.224`。

## 自己计算
1. 求 `10.20.30.70/26` 的块大小：`64`。
2. 网络边界为 `0、64、128、192`；70 落在 64–127。
3. 网络是 `10.20.30.64/26`，广播是 `10.20.30.127`。

## 细节和例外
- 普通 IPv4 子网通常保留网络与广播地址，但 `/31` 点到点链路与 `/32` 主机路由不能简单套“减 2”。
- 两端掩码配置不一致，会出现方向性或间歇性通信问题。
- IPv6 使用前缀长度，但没有 IPv4 式广播地址。
