# IPv6 除了地址更长，还有哪些网络变化

## 先用生活场景理解这个问题

你查看电脑网络信息，除了熟悉的 `192.168.1.10`，还发现冒号隔开的很长一串。这不是乱码，而是另一种 IP 地址格式。

## 本篇新术语，逐个落地

- **IPv4**：一种 32 位 IP 地址格式，常见写法为四段十进制数字。
- **IPv6**：一种 128 位 IP 地址格式，常见写法含冒号分隔的十六进制数字，地址空间更大。
- **双栈**：同一设备或网络同时支持 IPv4、IPv6，像同时能读两套地址簿。
- **NDP（邻居发现）**：IPv6 查询本地下一跳等信息的一套机制，作用上有部分地方类似 IPv4 的 ARP。

**学习前置**：[IP 是怎样的地址](../foundations/four-kinds-of-address.md) → [子网与路由](../ip-subnet-and-routing.md)。先能用自己的话解释这些知识，再看下面的技术机制。

**不改配置的最小观察**：Windows `ipconfig /all` 或 Linux `ip -6 addr`，观察本机有没有 IPv6 地址。记录一种地址格式并解释它不等于当前设备一定能访问 IPv6 公网。

## 再把生活里的问题对应到真实网络
一台电脑既有 `192.168.1.20`，又有 `2001:db8::20` 或 `fe80::...` 地址。它可能同时运行 IPv4 与 IPv6，这叫**双栈**，类似同时拥有两种邮政编码体系。

## 初学需要记住什么
- IPv4 地址长 32 位；IPv6 长 128 位，以冒号分隔的十六进制表示。
- `::` 可压缩一段连续的 0；`fe80::/10` 是链路本地范围，通常不能当公网地址直接用。
- IPv6 不使用 ARP，而用 ICMPv6 中的**邻居发现协议 NDP**；没有 IPv4 式广播。
- IPv6 常用 SLAAC、DHCPv6 或静态配置。不是“IPv6 无需防火墙”或“每台机器都会有固定公网地址”。

## 动手
```bash
# Linux
ip -6 addr
ip -6 route
# Windows
# ipconfig /all
# ping -6 ::1
```
本机 `::1` 是 IPv6 环回地址，像 IPv4 的 `127.0.0.1`。

## 常见问题
DNS 的 `A` 对应 IPv4，`AAAA` 对应 IPv6。应用“解析成功却连不上”，可能实际选中了错误地址族。可比较 `curl -4` 和 `curl -6` 的行为，但取决于网络支持。
