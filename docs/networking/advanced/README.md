不能独立解释时，请回到首次出现该名词的文章，而不是重新背一遍缩写。

## 按决策查
- 在选型和优化前定义目标：延迟分布、吞吐、丢包、可用性、资源成本、攻击面。
- 实验数据必须写明环境和工具，不用单次跑分替代架构论证。
