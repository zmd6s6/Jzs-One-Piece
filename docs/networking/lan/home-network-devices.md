# 家里的光猫、路由器、交换机和 Wi-Fi 各做什么

## 先看看你家有哪些东西

你用手机连上 Wi-Fi 就能上网，桌面电脑插网线也能上网。你看到的可能只有一个“路由器盒子”，但那台盒子内部其实承担了不同工作。

在学复杂的 ARP、交换和 IP 路由之前，先认出它们各自负责什么，就像先知道餐厅谁负责点餐、谁负责做菜。

## 一张不依赖技术术语的家庭网络图

```text
手机 ─── 无线信号 ──┐
                   │
电脑 ─── 网线 ─────┤ 家用网络设备 ── 光猫或入户设备 ── 运营商网络 ── 互联网
                   │
平板 ─── 无线信号 ─┘
```

不是每户都按这个顺序接线。很多设备集成了多种功能，可能光猫自带 Wi-Fi，也可能路由器直接接入墙上的网络口。

## 四个角色，用现实功能来分辨

**网卡（network interface）**：电脑或手机用来接入网络的接口，像设备通向外界的门；可以是有线网口，也可以是无线连接功能。

**交换机（switch）**：负责让同一个局域网里的设备互相交换数据。像大楼里的内部信件分拣员。下一篇会解释它怎样利用 MAC 地址转发。

**路由器（router）**：负责在不同网络之间选择转发方向，像从小区驶向外地的路口。它通过 IP 地址与路由表决定下一步去哪里。

**无线接入点（access point，AP）**：让手机通过 Wi-Fi 无线连接到网络，像提供一扇无线入口；它本身不自动等同于路由器。家用无线路由器常把 AP、交换机、路由等功能放在一个盒子里。

**光猫或调制解调设备**：负责匹配运营商提供的入户介质和接入方式，可以类比连接“小区道路”与“外部主干道路”的交接设备。它是否也承担路由、DHCP、Wi-Fi 取决于具体型号与配置。

## 什么叫局域网和互联网

**局域网（LAN）**：范围相对有限、由一方管理的本地网络，例如家里或办公室内的设备网络。

**互联网（Internet）**：许多不同网络相互连接后构成的全球性基础设施。网站、邮件等是使用互联网的应用服务，不等于互联网本身。

## 自己观察，不需要改配置

1. 找到你的路由器或入户设备，看哪些网口接着电脑、哪些设备通过 Wi-Fi 接入。
2. Windows 输入 `ipconfig`；Linux 输入 `ip addr`。看到的地址是**本机网络接口**的信息，不是你路由器的全部信息。
3. 尝试在 `ipconfig` 或 `ip route` 输出中找到“默认网关”（通往其他网络的常用第一站）；具体地址可能不一样。

不要在不理解影响时更改家庭路由器的 DHCP、桥接或入户设置。本篇只做观察。
