# 网站名字、电脑地址、网卡地址、端口号有什么不同

## 一个常见疑问

你打开一个网站时只记住了 `example.com`；网络信息里却出现 `192.168.1.20`、`00:11:22:33:44:55`、`443`。为什么同一趟通信需要这么多“号码”？

先想象你给外地朋友寄快递：你可能知道店名，但配送系统还要知道城市和楼栋、本地派件交接点，最后才能送到店里哪个柜台。**不同标识解决不同范围的定位问题**。

## 四种标识，分别解决四个问题

**① 域名：我想找哪家店？**

- 例子：`example.com` 是一种好记的网站名字。
- 类比：通讯录里记“张三”，而不是每次背一串号码。
- 作用：让人使用可记忆的名称；电脑可以通过查询服务找到相关网络地址。这个查询服务叫 [DNS（域名系统）](../dns-name-to-address.md)，后续专门学习。

**② IP 地址：应该把数据发往哪台设备或网络接口？**

- 例子：家里一台设备可能有 `192.168.1.20` 这样的私有地址。
- 类比：给跨城运输使用的收件地址。
- 作用：网络设备根据目标 IP 和路由规则转发数据。IP 不是永久不变的身份证；设备可以有多个 IP，地址也会改变。详见[IP 与路由](../ip-subnet-and-routing.md)。

**③ MAC 地址：在当前这段局域网里交给哪个网卡接口？**

- 例子：`00:11:22:33:44:55`（演示格式）。
- 类比：到达本地配送片区后，找到下一位配送员的交接标签。
- 作用：以太网等链路用它把一帧数据交给本地下一跳。跨过路由器后，链路层地址会根据下一段连接变化。MAC 也可能被软件改写，并非固定且全球唯一的身份证。详见[交换机与 ARP](../lan/ethernet-switch-arp.md)。

**④ 端口：到达目标设备后，交给哪个网络服务？**

- 例子：`:443` 是 HTTPS 常用的服务端端口号；`:8000` 可以是你自己启动的测试服务。
- 类比：快递送到大楼后还要找到具体的服务窗口。
- 作用：同一台机器可以同时运行网页、聊天、数据库等不同程序；端口让系统区分通信端点。TCP 和 UDP 有各自的端口空间。详见[传输层](../transport/tcp-vs-udp.md)。

## 把它们串成一条路

假设你想访问 `https://example.com:443`：

```text
好记的名字：example.com
    ↓ 查找目标地址
目标 IP：找到能提供服务的网络目标
    ↓ 路由决定“先发给谁”
本地下一跳的链路地址：让当前这一段路能交付
    ↓ 经过若干段网络
目标端口：把内容交给目标机器上的相应服务
```

这是一张**逻辑路径图**：查名字可能命中缓存，路由和本地交付涉及不同协议步骤，连接也可能复用，实际并非所有步骤每次都重来。

## 马上可以看到的东西

- Windows：打开命令提示符，输入 `ipconfig /all`，找到 IPv4 地址和“物理地址”（部分网卡可能是随机 MAC）。
- Linux：输入 `ip addr`，观察 `inet` 和 `link/ether`。
- 任一装有 `nslookup` 的电脑：运行 `nslookup example.com`，把返回地址与电脑自身 IP 对比。**返回的不一定是唯一 IP，也不是这台电脑自己的 IP。**

## 验收：四个问题不能混答

1. 已知网站名字，为什么还需要 IP？
2. 已知目标 IP，为什么局域网内还会用到 MAC？
3. 同一台服务器有两个网站程序，为什么需要端口？
4. 路由器转发后，本地链路地址和最终目的 IP 哪一个通常会变化？

能用自己的话答出用途而非只背缩写，就进入[局域网与网络接入](../lan/README.md)。
