# 在网页里写知识笔记

## 新建文章

1. 点击网站顶部或首页的「写文章」。
2. 使用 GitHub 登录 Pages CMS，打开 `zmd6s6/Jzs-One-Piece`，选择 `main` 分支。
3. 左侧选择分类，例如「随手记录」「C++」「AI 与 Agent」。
4. 新建文章，填写标题、摘要和正文。正文可以直接排版，也可以粘贴 Markdown；正文不需要重复填写文章标题。
5. 保存文章。等网站自动发布完成后，再打开知识库查看。

文件名会根据日期和标题生成；新建时可以修改，建议保持简短。首次使用后台需要完成 GitHub 的账户和仓库授权。

## 修改已有文章

在后台选择分类，搜索或打开文章，修改后保存。修改时将「更新日期」调整为当天日期。若文章使用了复杂 Markdown、公式或特殊语法，使用正文编辑器的 Source 模式保留原有内容。

## 插入图片

使用正文编辑器的图片功能上传图片，后台会保存并插入图片链接。普通分类与金融专题使用各自配置的图片来源，请保留当前分类默认的来源。

## 保存与发布

保存会触发网站更新，刷新网站前需等待发布任务完成。网站和仓库公开，后台登录权限用于控制谁能编辑，不会限制读者访问。

「内容成熟度」用于标记文章质量：整理中、持续更新、已稳定或已过时。它不控制是否公开；整理中的文章保存后也会发布。未准备公开的内容先保留在自己的本地草稿中。
